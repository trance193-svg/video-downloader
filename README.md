# Video Downloader (yt-dlp)

Расширение для браузера (Chrome / Edge / Brave), которое **находит видео на любом сайте и скачивает его со звуком** через связку [yt-dlp](https://github.com/yt-dlp/yt-dlp) + ffmpeg.

Расширение само по себе ничего не скачивает: оно обнаруживает видео (перехват сетевых запросов + скан страницы) и управляет локальным **native-хостом** — небольшой программой на Node.js, которая выполняет всю работу по загрузке через yt-dlp. Такой подход поддерживает HLS (`.m3u8`), DASH (`.mpd`) и автоматическую склейку видео + аудио в `.mp4`.

---

## Как это устроено

```
Страница с видео
   │  webRequest (перехват .m3u8/.mpd/.mp4/…) + content script (скан DOM)
   ▼
Расширение (MV3 service worker)  ←—→  Popup (интерфейс)
   │  chrome.runtime.connectNative
   ▼
Native host (Node.js, host/host.js)
   │  spawn
   ▼
yt-dlp.exe + ffmpeg.exe  →  файл в %USERPROFILE%\Downloads\VideoDownloader
```

- **`extension/`** — само расширение: детектор потоков и пульт управления.
- **`host/`** — native-хост: принимает команды расширения, запускает yt-dlp/ffmpeg, докладывает о прогрессе.
- **`tools/`** — вспомогательные скрипты (загрузка бинарников, генерация иконок).

## Требования

| Компонент | Зачем |
|---|---|
| Windows 10/11 | native-хост зарегистрирован через реестр Windows |
| Chrome, Edge или Brave | сам браузер (расширение в формате Manifest V3) |
| [Node.js](https://nodejs.org) (LTS) | на нём работает native-хост |
| `host/bin/yt-dlp.exe` и `host/bin/ffmpeg.exe` | скачиваются скриптом (см. шаг 1), уже могут лежать в репозитории |

## Установка

### Шаг 1. Проверьте бинарники yt-dlp и ffmpeg

Проверьте, что существуют `host\bin\yt-dlp.exe` и `host\bin\ffmpeg.exe`. Если их нет — скачайте автоматически (нужен интернет):

```bat
node tools\fetch_deps.js
```

Скрипт скачает yt-dlp с GitHub Releases и ffmpeg с gyan.dev и распакует в `host\bin\`.

### Шаг 2. Загрузите расширение в браузер

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите **режим разработчика** (переключатель справа сверху).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку **`extension`** внутри проекта.
5. На карточке расширения появится **ID** — 32 символа (например, `jikokcbmjann…`). **Скопируйте его** — он понадобится на следующем шаге.

### Шаг 3. Зарегистрируйте native-хост

В командной строке из корня проекта:

```bat
node host\install_host.js --extension-id=ВАШ_ID_ИЗ_ШАГА_2
```

Установщик:
- найдёт Node.js и создаст лаунчер `host\run_host.bat`;
- пропишет путь к лаунчеру и ID вашего расширения в манифест `host\com.videodownloader.host.json`;
- зарегистрирует хост в реестре (HKCU) для Chrome, Edge и Brave — права администратора не нужны.

### Шаг 4. Перезапустите браузер

Полностью закройте браузер и откройте снова — после этого расширение сможет связываться с хостом.

### Шаг 5. Проверьте установку

Быстрая проверка хоста без браузера (должен прийти ответ с информацией о yt-dlp):

```bat
node test_host.js
```

Затем откройте расширение (иконка на панели) — вверху попапа должен гореть статус **«host: подключён»**.

## Использование

1. Откройте сайт с видео и **запустите воспроизведение** — расширение перехватывает потоки, пока страница открыта.
2. Кликните иконку расширения. В попапе:
   - **Перехваченные потоки** — прямые ссылки на видео/аудио/манифесты, найденные на текущей вкладке. У манифестов (`.m3u8`) есть ссылка «анализ».
   - **«Найти видео (yt-dlp)»** — большая кнопка: берёт лучший найденный поток (приоритет у master-манифеста HLS) или адрес страницы и просит yt-dlp разобрать ссылку.
   - **Ручной ввод** — можно просто вставить любую ссылку на видео/страницу.
3. После анализа появится список форматов: «Наилучшее со звуком» (видео+аудио, склеивается в `.mp4`), отдельные видео-дорожки (качества), progressive-форматы.
4. Нажмите **«Скачать»** — появится прогресс-бар (проценты, скорость, время до конца). Отменить можно кнопкой **«Отмена»**.
5. Готовый файл лежит в:

```
%USERPROFILE%\Downloads\VideoDownloader\<имя видео>.mp4
```

Имя файла берётся из заголовка страницы.

## Устранение неполадок

| Симптом | Решение |
|---|---|
| Статус «host: не подключён» | 1) Проверьте, что Node.js установлен (`node --version`). 2) Перезапустите `node host\install_host.js --extension-id=ВАШ_ID` и полностью перезапустите браузер. 3) Проверьте `node test_host.js` |
| Расширение в браузере серое/ошибки на `chrome://extensions` | Нажмите «Ошибки» на карточке расширения и сообщите содержимое; попробуйте удалить и загрузить расширение заново |
| «Анализ» падает с ошибкой yt-dlp | Сайт может отдавать видео только по сессии/токенам, либо использовать DRM — такие видео не поддерживаются. Попробуйте вставить прямую ссылку вручную |
| Скачался файл без звука / в `.mkv` | Возможна недоступность ffmpeg. Убедитесь, что `host\bin\ffmpeg.exe` существует |
| ID расширения изменился | ID распакованного расширения зависит от полного пути к папке. Если вы переместили проект — загрузите расширение заново и повторите шаг 3 |
| Скачивание молча оборвалось | Сервис-воркер расширения мог заснуть. Откройте попап и запустите скачивание заново |

## Структура проекта

```
video-downloader/
├── README.md                  ← этот файл
├── test_host.js               ← smoke-тест native-хоста (PING через лаунчер)
├── test_list.js               ← тест анализа: node test_list.js <URL> → список форматов
├── extension/                 ← расширение (Manifest V3)
│   ├── manifest.json          ← разрешения и точки входа
│   ├── background.js          ← service worker: перехват потоков, связь с host
│   ├── content.js             ← скан страницы на <video>/<iframe>
│   ├── popup.html/css/js      ← интерфейс
│   └── icons/                 ← иконки 16/48/128
├── host/                      ← native messaging host
│   ├── host.js                ← протокол Chrome + запуск yt-dlp/ffmpeg
│   ├── install_host.js        ← установщик (реестр + манифест + лаунчер)
│   ├── com.videodownloader.host.json ← манифест хоста (генерируется)
│   ├── run_host.bat           ← лаунчер (генерируется установщиком)
│   └── bin/                   ← yt-dlp.exe, ffmpeg.exe
└── tools/
    ├── fetch_deps.js          ← загрузка yt-dlp/ffmpeg в host/bin
    └── gen_icons.js           ← генератор иконок
```

## Ограничения

- Только Windows и Chromium-браузеры (Chrome / Edge / Brave). Firefox и macOS/Linux не поддерживаются.
- Видео с DRM (Netflix, платные стриминги и т.п.) скачать нельзя.
- Одновременно выполняется одна задача (анализ или скачивание).
- Расширение загружается как «распакованное» — ID зависит от пути к папке проекта; при перемещении проекта повторите шаг 3.
- Бинарники в `host/bin/` (~115 МБ) не должны попадать в git — при публикации репозитория добавьте `host/bin/` в `.gitignore` и раздайте бинарники через `node tools\fetch_deps.js`.
